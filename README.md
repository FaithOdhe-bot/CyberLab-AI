### Problem Statement & Market Gap
The average cost of a data breach is $4.9M, yet small businesses remain vastly underserved. Many lack the budget for full-time SOC analysts or enterprise-grade security tools, leaving them vulnerable to sophisticated attacks. CyberLab AI bridges this gap.

### 4-Dimensional Adaptive Intelligence Framework
CyberLab AI dynamically adjusts its responses across 14 distinct User Personas, including: Cybersecurity Student, SOC Analyst, Pen Tester, IT Practitioner, IT Manager, Network Engineer, Developer, Business Owner, Educator, Sales Engineer, Data Professional, Project Manager, Financial Analyst.

### 10+ Widget Modular System
- **TL;DR:** High-level summary of the issue.
- **Quick Read:** Fast, actionable insights.
- **Diagnose:** Root cause analysis.
- **Respond:** 60-minute incident containment playbook.
- **Harden:** Proactive security controls.
- **Cloud:** Cloud infrastructure/Console remediation paths.
- **Map:** Blast radius and dependency mapping.
- **Translate:** Layman explanation for non-technical stakeholders.
- **Comply:** Audit and compliance gap analysis.
- **Simulate:** Attack simulation scenarios.
- **Learn:** Educational deep-dives.

### Full-Stack AWS Serverless Architecture (Phase 2)
The phase 2 architecture relies on a highly scalable, serverless AWS footprint:
S3/CloudFront -> WAF -> API Gateway -> Lambda -> Bedrock Claude Sonnet -> DynamoDB -> Cognito.

### Security Architecture
Built with security at the core:
- **SSRF Protection:** Strict validation of outbound requests.
- **AWS WAF:** Rate limiting and payload inspection.
- **Least-Privilege IAM:** Strict policy constraints for Lambda and Bedrock access.
